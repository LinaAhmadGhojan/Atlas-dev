# Portfolio Website

This workspace now contains a responsive portfolio website for showcasing all your work.

## Files

- index.html: main page structure
- styles.css: visual design and responsive behavior
- script.js: project data and dynamic filtering

## Quick Start

1. Open index.html in your browser.
2. Edit your personal details in index.html.
3. Add all your projects by updating the projects array in script.js.
4. Replace placeholder links for GitHub, LinkedIn, and each project case study.

## Tips

- Duplicate a project object in script.js to add more work.
- Keep category values aligned with filter names: web, mobile, data, enterprise.
- You can change colors quickly from CSS variables at the top of styles.css.
